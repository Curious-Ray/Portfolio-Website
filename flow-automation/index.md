# Flow Automation

> Flow Automation is an independent no-code browser extension that lets non-technical creators batch-run Google Flow video prompts from their own Flow browser session.

## What it does

Flow Automation turns repeated Google Flow prompt work into a tracked batch workflow. Users import or type prompts, choose a workflow on Flow, run the queue, and let the extension handle pacing, retries, downloads, and reporting. It works inside the Flow page and browser session the user opens, so the user stays in control of their own Google account, Flow settings, and generated outputs. No MCP setup, API client, command-line tool, or coding workflow is required.

## Key features

- Bulk prompt queue for Google Flow video workflows.
- Prompt import from spreadsheets, CSV files, and text files.
- Text to Video, Frames to Video, and Ingredients to Video modes.
- Adjacent and grouped start/end frame pairing.
- Prompt/image matching for reference-image (ingredient) workflows.
- Repeat runs per prompt for variation pulls.
- Retry handling, pacing controls, and live action logs.
- Organized downloads with folder and filename options.
- CSV run reports for completed batches.

## Affiliation

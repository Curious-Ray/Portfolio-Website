For faster troubleshooting

Include the details that apply to the problem:

  • browser name and version;
  • Higgsfield Automation version, shown in the extension interface or browser extension page;
  • selected workflow, such as Text to Image or Frame to Video;
  • the exact error message;
  • steps that reliably reproduce the problem;
  • a short, redacted action-log excerpt or screenshot;
  • whether the issue still occurs after refreshing the Higgsfield tab.

Selector configuration errors

If the extension says it could not load the current selector configuration, open the Cloudflare selector endpoint in the same browser profile. Mention whether the page displays JSON or fails to open.

Privacy and deletion requests

Use the subject line Higgsfield Automation privacy request and send the request from the email address associated with your extension sign-in when account verification is necessary. See the Privacy Policy for storage, retention, and deletion details.

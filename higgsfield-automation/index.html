FAQ

Clear answers before install.

What browsers are supported?

Chrome, Microsoft Edge, and Mozilla Firefox each have their own official listing, so you install the build signed for your browser. The Chrome Web Store listing requires Chrome 114 or newer; other Chromium browsers such as Brave, Arc, and Opera can install that same build. Safari is not currently supported.

Do I choose the Higgsfield model in the extension?

No — you set the model, aspect ratio, duration, and resolution on higgsfield.ai. The extension runs against the page and settings you have selected.

Do I need MCP, APIs, or coding?

No. Higgsfield Automation is built for non-technical creators. Choose a workflow, paste or import prompts, click Run, and the extension handles the repeated browser actions inside your Higgsfield session.

Can it chain prompts together?

Yes. Start a prompt with ">>" to feed the previous output into the next — useful for continuous shots or iterative edits.

Does it work without a Higgsfield account?

No. You need a higgsfield.ai account signed in in your browser. The extension does not create an account or log in for you.

Is this official Higgsfield software?

No. It is an independent browser extension by Deepak Thapa, not affiliated with or endorsed by Higgsfield.

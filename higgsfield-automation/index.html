FAQ

Clear answers before install.

What browsers are supported?

The Chrome Web Store listing requires Google Chrome 114 or newer. Other Chromium browsers work if they support installing Chrome Web Store extensions.

Do I choose the Higgsfield model in the extension?

No — you set the model, aspect ratio, duration, and resolution on higgsfield.ai. The extension runs against the page and settings you have selected.

Can it chain prompts together?

Yes. Start a prompt with ">>" to feed the previous output into the next — useful for continuous shots or iterative edits.

Does it work without a Higgsfield account?

No. You need a higgsfield.ai account signed in in your browser. The extension does not create an account or log in for you.

Is this official Higgsfield software?

No. It is an independent Chrome extension by Deepak Thapa, not affiliated with or endorsed by Higgsfield.

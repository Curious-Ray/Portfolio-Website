// WHAT'S INSIDE

Everything you'd do by hand — on autopilot.

01 · BULK QUEUE

Bulk generation on autopilot

Paste 10 prompts or 500. The queue runs them one after another inside your own Magnific session — you press start once and it handles the rest.

  • One prompt per line, no setup
  • Runs in order with live progress
  • Works best with the Magnific tab visible

02 · IMAGE + VIDEO

Images and videos, one queue

Text-to-video, image-to-video, frame pairs, text-to-image — whatever Magnific supports, the queue drives it with your chosen settings applied to every run.

  • Lock resolution, concurrency & delay once
  • Applied to every generation automatically
  • Mix image and video jobs in a batch

03 · LIVE PROGRESS

Queue everything, watch it run

A live activity panel shows each job as it works — queued, running, done. If something fails, pick up where you left off instead of starting the whole batch over.

  • Real-time status for every prompt
  • Resume after a failure
  • See exactly what finished

04 · PROMPT MATCHING

Every image matched to its prompt

No more guessing which output came from which prompt. Each result is paired to the line that made it, so a 200-image batch stays perfectly organized.

  • Prompt ↔ image pairing
  • No confusion at volume
  • Clean records for every run

05 · AUTO-DOWNLOAD

Downloaded and organized

Optional auto-download per generation with sequenced, prompt-based filenames — plus a CSV log of every prompt and result so your output folder and your records stay tidy.

  • Auto-download to your Downloads folder
  • Numbered, prompt-based filenames
  • CSV export of the whole batch
